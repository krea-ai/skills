# Storyboard Variations

Use this when a social video, UGC, ad, or campaign brief is creatively loose. Storyboard variants are cheap compared with video; use them to explore direction before committing.

## Locked vs Loose

- **Locked**: user provided casting/persona, setting, tone, reference, and required beats. Generate one storyboard unless they ask for options.
- **Loose**: any of casting/persona, setting, tone, reference, or concept is missing. Default to 3 parallel storyboard variants.

Each loose-brief variant must move at least two axes so the options are meaningfully different.

## Variation Axes

| Axis | Useful options |
|---|---|
| Persona / casting | gen-z creator, mid-20s professional, parent, post-gym athlete, older creator, niche hobbyist |
| Setting / location | bedroom, kitchen, car, street, office desk, gym/locker room, coffee shop, outdoors |
| Tone | candid confession, review/testimonial, GRWM, POV reveal, comic interruption, quiet premium, absurd deadpan |
| Concept / premise | realistic UGC, anachronistic roleplay, fish-out-of-water, mascot POV, alternate era, impossible scale |
| Time of day | morning, midday, golden hour, late night |
| Format hook | caption sticker open, reaction open, product close-up open, question open, before/after open |

## Delivery Pattern

When delivering multiple storyboard variants:

1. Label them clearly: `A`, `B`, `C`.
2. Send each variant with a one-line caption naming the creative direction.
3. End with one short pick-list line so the user can reply with a letter.
4. Do not auto-pick a winner.
5. Do not animate until the user explicitly chooses or combines variants.
